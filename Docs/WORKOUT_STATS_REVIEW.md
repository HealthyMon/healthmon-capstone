## 발견한 누락과 수정

관절 운동 화면의 종료 처리는 `pose-workouts.json`에 횟수만 저장하고 공통 게임 서버에 전달하지 않았습니다. 따라서 카메라 횟수 측정 성공만으로 캐릭터 성장이 검증됐다고 볼 수 없었습니다.

- 운동 시작 시 서버 인스턴스·소유자·캐릭터를 고정하고, 종료 시 `POST /pets/{pet}/workouts`로 횟수와 운동 시작/완료 시각을 전달합니다.
- 스쿼트와 푸시업은 해당 운동으로, 관절 서비스의 `curl`은 서버의 `dumbbell`로 연결합니다. 컬의 `count`는 관절 서비스가 제공하는 좌우 합계입니다.
- `pose-{session_id}`를 기록 ID로 고정합니다. 전송 전에 별도 로컬 대기 파일에 저장하고, 재연결·재시작 시 같은 내용과 ID로 재전송합니다.
- 다른 서버·계정·캐릭터의 대기 기록을 현재 캐릭터에 붙이지 않습니다. 과거의 귀속 정보 없는 기기 기록도 자동 업로드하지 않습니다.
- 서버가 반환한 상태를 기존 상태 변경 이벤트로 전달하여 홈·상태·전투 수치가 같은 상태를 사용하게 했습니다. 결과 화면의 성장 반영 문구는 서버 응답 후 표시합니다.
- 서버 연결 없이 시작한 운동은 기존 기기 내 기록으로 유지합니다. 이 변경은 오프라인 육성 규칙을 새로 추가하지 않습니다.
