# 성장 스탯에서 전투 능력치로

상태창·관리자 미리보기·탐험·일반전·정예전은 Unity의 `PetCombatStats.Calculate`에서 같은 캐릭터의 기본 전투 능력치를 계산한다.

## 값의 전달

- 온라인: 관리자 테스트 API 또는 일반 운동·식사·대화/퀘스트의 서버 응답 → CommonServerConnection.LatestState → PetCombatStats.
- 상태 보기와 관리자 결과 요약은 같은 PetCombatStats를 표시한다.
- 일반전·정예전은 전투 직전 최신 결과를 AdventurePlayerStats에서 BattleUnit으로 복사한다.
- 전투 중에는 스냅샷을 고정한다. 도중에 받은 변경은 다음 전투부터 적용한다.
- 같은 펫의 레벨/능력치가 바뀌면 현재 HP/ST 비율을 유지한다. 새로 고침으로 완전 회복하거나 부활하지 않는다.
- 전투 종료 때는 현재 HP/ST만 탐험으로 가져온다. 전투 중 버프를 영구 성장 수치로 역저장하지 않는다.
- 다른 서버·계정·펫으로 바뀌면 별도 탐험 자원 상태로 초기화한다.
- 처음 접속하기 전에는 Inspector 샘플값으로 서버 모드 전투를 시작하지 않는다.
- 오프라인은 선택된 펫의 로컬 레벨/생활 기록을 사용하고 씬 이동 전에 스냅샷을 보관한다. 로컬에 없는 영양·에너지 점수는 중립값(50/0)을 사용한다.
- 탐험 중 획득한 능력치 보너스는 탐험에만 더한다. 체크포인트에는 보너스를 기본 능력치와 별도로 저장해, 다시 들어와도 최신 성장값에 한 번만 합산한다. 보너스 구분이 없는 이전 저장 파일은 층·아이템과 현재 HP/ST 비율을 복원하고 새 공식으로 기본 능력치를 산출한다.

## 공통 공식

레벨 L은 1~30이다. 표에서 g = L − 1이다. 상체·하체·영양·활동성·친밀도·주도성은 (점수 − 50) / 50으로 정규화한다. 에너지 항은 −|에너지 균형| / 100으로, 0이 중립이며 같은 크기의 과잉과 부족은 같은 감점을 받는다.

기본 전투 능력치 = 레벨 기본값 × (1 + 0.30 × 가중 성장 점수). 각 행의 가중치 합은 1이다. 정수 능력치는 반올림하고 최대 ST는 소수 첫째 자리까지 반올림한다. 정확히 절반인 값은 올림한다.

| 능력치 | 레벨 기본값 | 상체 | 하체 | 영양 | 활동성 | 친밀도 | 주도성 | 에너지 항 |
|---|---|---:|---:|---:|---:|---:|---:|---:|
| 최대 HP | 100 + 6g | .15 | .30 | .25 | .10 | 0 | 0 | .20 |
| 최대 ST | 20 + g | 0 | .30 | 0 | .50 | 0 | .15 | .05 |
| ATK | 10 + 1.2g | .45 | .15 | .10 | .15 | 0 | .15 | 0 |
| DEF | 5 + .5g | .40 | .35 | .15 | 0 | 0 | 0 | .10 |
| RES | 5 + .5g | 0 | 0 | .60 | .20 | 0 | .10 | .10 |
| SPD | 5 + .25g | 0 | .50 | 0 | .35 | 0 | .10 | .05 |
| LUK | 5 + .20g | 0 | 0 | 0 | .10 | .45 | .45 | 0 |

공통식과 공격력 계수는 팀 발표 슬라이드에 명시된 값이다. 나머지 6개 행의 레벨 계수·가중치와 에너지 항의 스케일은 슬라이드의 반영 요소와 예시 7개 수치를 충족하도록 이 구현에서 정했다.

**Lv.10 예시** — 상체 80, 하체 60, 영양 70, 에너지 균형 +8, 활동성 75, 친밀도 40, 주도성 85. 공격력 가중 점수는 0.52이며 20.8 × 1.156 = 24.0448이다.

| 최대 HP | 최대 ST | ATK | DEF | RES | SPD | LUK |
|---:|---:|---:|---:|---:|---:|---:|
| 167 | 32.6 | 24 | 11 | 11 | 8 | 7 |

## 전투 시 적용

ATK·DEF·RES는 피해량에, SPD는 행동 게이지 충전에, LUK는 치명타 확률에 쓰인다. 탐험의 현재 HP와 ST는 전투 진입·복귀 때 전달한다. 첫 입장 시 HP는 최대치, ST는 최대치의 절반이다. 상태창은 최대치, 탐험과 전투 UI는 현재치와 최대치를 표시한다.

체형 판정은 서버의 진화 기준을 따른다. 기존 행동 속도 배율(비만형 ×0.5, 통통형 ×0.8, 벌크 운동형 ×0.9, 마른형 ×1.1, 마른 운동형 ×1.15)과 영양·체형에 따른 ST 회복 배율은 행동 게이지와 회복량에 따로 적용한다. 위 표의 7가지 능력치에는 추가 체형 배율을 곱하지 않는다.

기존 전투 기능의 구현 이력과 이전 밸런스 수식은 [변경 전 설계 기록](https://github.com/HealthyMon/healthmon-capstone/blob/ee57e38699414e6a7b7936055b8df2544eb8a56a/Docs/COMBAT_STATS.md)에 있다.

## 검증

`Client/HealthMonUnity/Tests/CombatStatsChecks.cs`는 슬라이드의 일곱 결과, 중립·상하한·에너지 대칭성과 서버 체형 판정을 확인한다. `HealthMonTeamIntegration.VerifyAdventure`는 탐험에서 전투로 전달되는 수치와 체크포인트의 자원 복원을 검증한다.
