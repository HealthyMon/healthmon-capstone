# DishSeg 추가 학습 결과 (2026-11-08)

추가 학습 3 epoch 완료. `runs/food_regions_dishseg/food_regions.pth`를 `active_region.json`으로 기본 실행 모델에 연결했습니다. `Run-FoodAI.ps1`에서 자동 사용합니다.

## 학습 자료

- DishSeg train: 중복 26장, 주석/실제 해상도 불일치 1장을 제외한 19,338장, 음식 박스 90,045개.
- UEC train 600장을 4회 반복하여 replay에 사용.
- 기존 UEC 위치 모델에서 학습, 입력 480/800, batch 8, SGD 0.001, mixed precision, 3 epoch.
- 평균 학습 loss: 0.487309 → 0.454207 → 0.423971.
- 원본 데이터는 변경하지 않았습니다. 입력 해상도 증가도 개선에 포함됩니다.

## 최종 평가 한 번

학습 종료 후 동일 사진으로 이전/신규 위치 모델을 비교했습니다. 점수 ≥0.5, 정답 IoU ≥0.5, 음식 클래스 구분 없는 위치 평가입니다. 음식명 정확도가 아닙니다.

| 평가 | 기존 | 신규 |
|---|---:|---:|
| DishSeg 다중 음식 4,706장 precision | 94.43% | 97.54% |
| DishSeg 다중 음식 recall | 89.57% | 95.32% |
| DishSeg 다중 음식 F1 | 91.94% | 96.41% |
| DishSeg 전체 4,720장 F1 | 91.92% | 96.40% |
| DishSeg 전체 mAP50:95 (score ≥0.05) | 65.49% | 85.90% |

| UEC 기존 평가 recall | 75.00% | 71.88% |

공식 test 4,731장 중 train/replay와 원본 SHA256이 같은 11장을 제외했습니다. 유사 이미지까지 제거했다는 보장은 없습니다. 사전에 정한 'DishSeg F1 개선 + UEC F1 하락 5%p 이내' 조건을 통과하여 신규 모델을 선택했습니다. 이 test는 배포 모델 선택에도 사용했으므로 완전히 독립적인 최종 배포 평가로 해석하지 않습니다. 결과를 보고 재학습하거나 임계값을 조정하지 않았습니다.

기능 테스트 8개 통과. 기존 중량 모델 로드 통과(중량 정확도 평가 아님). 상세 기록: `outputs/final_dishseg/metrics.json`, `tests.txt`.

## 한계 및 실제 입력

음식 영역을 찾는 모델이며 물리적인 접시 개수 검출기가 아닙니다. 기존 AI Hub 800종 음식명 모델과 중량 모델은 그대로입니다.

사용자가 제공한 앱 화면 전체 이미지에서는 4개 영역이 검출되었으나, 아래 카드 썸네일까지 검출하고 상단 돈가스/샐러드를 하나로 묶으며 일부 음식이 누락되었습니다. 4개 모두 이름은 '미확인 음식'입니다. 따라서 해당 예시 화면의 모든 음식 구분·명명까지 완성된 상태는 아닙니다. 앱에서는 UI 스크린샷이 아니라 촬영 원본 사진을 AI 입력으로 전달해야 합니다. 한식 실사진 및 같은 접시 위 반찬 분리 성능은 별도 데이터로 확인해야 합니다.

중량은 기존 cuboid 입력이 없으면 null을 반환합니다.
