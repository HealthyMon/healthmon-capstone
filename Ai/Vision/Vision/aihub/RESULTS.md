- 3 epoch, training loss: 0.8618 → 0.7720 → 0.6709
- 기존 AI Hub 800종 탐지 가중치와 중량 가중치의 SHA256은 원본과 동일

## 한 번의 최종 평가

공식 UEC test에서 분리해 둔 96장, 총 256개 영역. IoU≥0.5 일대일 매칭의 클래스 무관 위치 평가입니다. baseline 임계값은 0.35, 새 위치 모델은 0.5입니다. 같은 종류가 붙어 있는 경우를 분리하지 못하는 semantic mask 기반 정답이므로 실제 접시 instance 평가가 아닙니다.

| 평가 범위 | 모델 | 정밀도 | 재현율 | F1 |
|---|---|---:|---:|---:|
| 전체 96장 | 기존 AI Hub | 59.7% | 14.5% | 23.3% |
| 전체 96장 | 새 위치 모델 | 86.1% | 75.0% | 80.2% |
| 다중 음식 72장 | 기존 AI Hub | 58.2% | 13.8% | 22.3% |
| 다중 음식 72장 | 새 위치 모델 | 87.5% | 72.4% | 79.2% |

계약 테스트 8개 통과, 기존 중량 모델 로드 성공. 실제 중량 추론 정확도는 평가하지 않았습니다.

## 남은 한계

- 음식 이름 정확도는 개선·검증한 지표가 아닙니다. 기존 800종 모델을 그대로 사용합니다.
- 사용자 UI 스크린샷에서는 6개 영역을 반환했지만 이름은 모두 `미확인 음식`이었습니다. UI 카드 속 음식도 탐지 대상이므로 6개가 실제 식사의 정답 개수라는 뜻은 아닙니다.
- 정답 cuboid 또는 기존 cuboid 예측기가 연결되지 않으면 중량은 null입니다.
- 600장/3 epoch의 초기 위치 모델이며 새로운 촬영 환경과 작은 반찬까지 포괄하는 성능은 별도 자료가 필요합니다.
