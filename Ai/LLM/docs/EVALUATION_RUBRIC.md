# 원문·서버 결과 평가 기준

검토 주체는 Codex다. 사람 평가가 아니며, 소규모 직접 작성 시험의 오류 발견 수를 실제 사용자 전체 정확도로 해석하지 않는다. 동일 턴에 여러 오류 유형이 붙을 수 있으므로 유형별 건수를 더해 실패 턴 수로 삼지 않는다.

* JSON 문법: 첫 생성의 전체 원문이 JSON 한 개로 파싱되는가. Pydantic schema/enum 위반은 별도 집계한다.
* 기억·사실: 제공된 유효 기억/사용자 발언/활동 합계와 모순되는가, 없는 개인 사실·수치·기록을 단정하는가, 요청된 명확한 사실이 있는데 없다고 하거나 다른 답으로 회피하는가. 기억 ID가 존재한다는 이유만으로 내용까지 맞다고 보지 않는다. 장난의 명백한 비유 자체는 사용자 사실 환각으로 세지 않는다.
* 말투·한국어: 설정 존댓말 위반, 사용자 직접 모욕, 한국어 문법·어휘의 명백한 이상, 강제 상태 시험에서 요청 성격이 드러나지 않는 경우. 약한 비속어는 허용이지 매번 의무가 아니므로 단어 '젠장'의 부재만으로 실패를 주지 않는다.
* 오거절: 정상 운동·교감·격려 요청을 과제 대행 등으로 오인해 거절하는 경우. 기술적 fallback은 오거절과 별개로 집계한다.
* 불필요 반복: 최근 응답과 거의 같은 문장 또는 같은 불필요한 회피 행동을 반복한다. 정확한 사실 재확인과 짧은 인사의 의미상 유사함만으로 실패를 주지 않는다.
* 퀘스트: 후보/진행 상태와 맞지 않는 제안·완료·보상 주장, 잘못된 action/ID, 명시적 요청과 가능한 후보가 있는데 실제 offer action을 누락한 경우. 쉬고 싶음·거절 이력에는 보류해야 한다.

원문 품질은 첫 번째 생성만으로 판정한다. 재생성 원문은 attempts에 별도 보관한다. 서버 결과는 검증·최대 한 번 재생성·fallback 뒤의 응답이다. 서버가 반환한 JSON의 유효성은 원문 모델 성공률이 아니다. fallback이 안전한 부재 안내를 하더라도 원문 모델 성공으로 승격하지 않는다. 별도 fallback 비율, 동일 기본 문장 수, 남은 응답 부재를 함께 제시한다.

58건 최종 입력은 세 모델에 같은 시스템 프롬프트, 상태·기억, token budget, temperature=0.7/top_p=0.9/repetition_penalty=1.05, 예제별 난수 seed(9100+index)를 사용한다. 먼저 가중치를 로드한 다음 각 예제 직전에 seed를 재설정한다. 골드 기대값은 모델 입력에 넣지 않는다. 스타일 변형 등 관련 사례가 있으므로 58개를 모두 통계적으로 독립인 실제 사용자로 세지 않는다. 선택용 검증과 최종 시험은 분리했다.
