## 학습

Qwen3.5-4B의 기존 HealthMon SFT LoRA에서 추가 학습했다. NF4 QLoRA rank 8, 학습률 0.00006, 2 epochs, 88 optimizer steps. 총 352건 중 256건은 활동성·친밀도·주도성의 8가지 저/고 조합(0/100 및 20/80), 72건은 단일 축 대조, 8건은 기억 유지, 16건은 휴식·거절 존중 예시다. 같은 최근 발화에서도 현재 파라미터를 우선하도록 학습했다. 원본 AI Hub 및 사용자 데이터는 변경하지 않았다.

학습 당시 요청에 따라 validation loss 평가를 생략했다. 이후 사용자의 새 요청으로 아래 최종 실응답 비교를 실행했다. 추론 속도 최적화는 유지했다.

## 비교 조건

실제 실행 중인 GPU gateway `/v1/chat`에 합성 요청 24건을 보냈다. 학습에 쓰지 않은 종이배·동네 빵집·선물 받은 퍼즐 문장을 대상으로, 다른 축을 50으로 고정하고 한 축만 0/100으로 바꿨다. 최근 대화도 동일하게 고정했다. 혼합 조합 4건과 질문 거부·기억 회상 2건을 추가했다. 서버의 고정 생성 seed 정책을 사용했다.

이는 현재 모델 내부의 파라미터 비교이며 이전 모델/9B와의 전후 비교가 아니다. 하나의 seed와 소수 문장에 대한 정성 검토이므로 전체 성능이나 안정적인 중간 수치 보간을 입증하지 않는다. Unity 화면 및 APK까지 검증한 것은 아니다.

## 관찰 결과

- HTTP 및 응답 계약: 24/24 정상. 이는 의미 품질 통과율이 아니다.
- 활동성: 3/3쌍에서 낮을 때 차분하고 높을 때 감탄·활기 있는 표현이 나타났다.
- 주도성: 3/3쌍에서 낮을 때 질문 없이 끝나고 높을 때 후속 질문이 나타났다. 다만 퍼즐에 대한 ‘어떤 그림자가’는 부적절한 어휘다.
- 친밀도: 3/3쌍에서 높은 값의 반응이 더 길고 정서적으로 표현됐으나 활동성과 표현이 일부 겹쳤다. 독립적인 친밀도 제어가 충분히 검증됐다고 볼 수 없다.
- 혼합 조합: 4건에서 낮은 활동성+높은 주도성은 차분한 질문, 높은 활동성+낮은 주도성은 활기찬 반응 후 종료로 구분됐다. 그러나 화분만 언급했는데 꽃이 있다고 가정했다.
- 질문 거부: 주도성 100에서도 질문하지 않았다.
- 기억 회상: 바뀐 차 ‘둥굴레차’를 회상했지만 ‘즐겨riding’이라는 언어 혼입 오류가 있었다.
- 서버 응답 시간은 약 3.0~4.1초였다. Unity 및 전체 API 경로 지연은 포함하지 않는다.

## 남은 문제

반말 설정의 ‘만드셨구나’, 한자 혼입 ‘새로到手의’, 영어 혼입 ‘즐겨riding’, ‘접지 배’, ‘그림자가’ 등 자연스러움 오류가 남았다. 빵집에 다녀왔다는 말만으로 먹었다고 가정하거나 오랜만에 간 곳을 새로 간 곳이라고 바꾸는 맥락 오류도 있었다. 파라미터에 따른 차이는 관찰됐지만 자연스러운 한국어와 사실 보존은 해결 완료로 처리하지 않는다. 다음 개선 시 이 출력들을 잘못된 예시로 모으고, 언어 혼입·근거 없는 추측을 제거한 대조 정답을 다양하게 보강할 필요가 있다.
