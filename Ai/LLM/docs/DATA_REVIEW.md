# 파일럿 데이터 검수

원본 연구실 데이터는 확보되지 않았다. `data/pilot_v2`의 train 34/validation 8은 이번 작업에서 Codex가 직접 작성한 한국어 게임 예시다. 사람 승인이나 AI Hub 출처가 아니다. 시나리오 묶음 단위 분할, canonical schema, 기억/후보 ID, 정답 형식, assistant 토큰 마스킹, 1024토큰 초과 여부를 검증했다. 최대 660토큰, 잘림 0건.

`data/pilot_v1`은 첫 초안이다. Transformers 5의 apply_chat_template 반환형을 목록으로 잘못 간주해 토큰 수가 잘못 측정된 메타데이터가 있다. 기존 초안을 보존하고 `return_dict=False`로 수정한 v2를 만들었다. 학습에는 v2만 사용했다. sample_id는 내용 계보를 유지하기 위해 pilot-v1-* 접두어를 유지한다.

학습 데이터의 기억 ID/퀘스트 ID는 입력에 명시한 가상의 게임 시나리오 근거다. 실사용자 기록을 수집했다고 주장하지 않는다. 실제 대화가 학습 파일에 자동 추가되지 않는다.

형식 검토: Python 검증 통과. 의미 검토: 작성 에이전트 검토, 독립 사람 검토 없음. 외부 공개 데이터 미사용. train800/val100/test200 확장 미완료, 최종 동결 test는 아직 0건이다. 검증 8건은 체크포인트 선택·개발에 노출되었으므로 최종 시험으로 사용할 수 없다.

현재 분포가 작고 데이터에 단일 턴이 많다. 장기 말투 변화, 다중 세션 자연 교감, 충분한 의역, 거친 말투/새침함, 의미적 사실 일치와 역할 우회 사례를 독립 원본 시나리오로 더 작성·검수해야 한다. 숫자를 맞추기 위한 무검수 자동 증식은 하지 않았다.
