# Persona 데이터 품질 감사

감사일: 2026-10-01. 작업 경로: `E:\qwen-llm`. 원본을 읽어 계산한 결과이며, 새 학습 데이터 생성이나 LoRA 학습은 수행하지 않았다.

**현재 데이터의 분류는 ‘기존 7축에 대한 제한된 Persona 학습용’이다. 새 네 성격축 학습용 또는 최종 모델 학습용으로는 부족하다.** `curiosity`, `affection`, `activity`, `confidence`는 모든 기존 학습·검증·시험 레코드에서 빠져 있다. 기존 `initiative`나 `bond`를 새 축으로 임의 환산하지 않았다. 출력 형식·근거·일부 말투의 예제로 보존할 가치는 있다.

이 문서는 데이터만 평가한다. 현재 epoch 1 LoRA의 실제 네 축 반응 여부는 별도의 실제 Qwen A/B 결과로 판정해야 한다. 데이터에 축이 없다는 사실과, 사전학습 모델이 새 style profile을 어느 정도 따를 수 있는지는 다른 문제다.

## 정확 중복, 근접 중복, 분할 오염

v3 내부의 동일 사용자 입력은 train 7그룹/27레코드, validation 2그룹/9레코드, test 2그룹/10레코드다. 상당수는 의도된 옛 스타일 비교라 단순 삭제 대상이 아니다. 동일 `(context, user_text)`는 각 분할에서 0건이다.

동일 assistant speech는 train에 **1쌍** 있다. `improvement-v1-083`과 `expanded-v2-0193`의 사용자 입력은 다르지만 답변은 모두 다음과 같다.

> 500걸음 걷기 퀘스트를 제안할 수 있어. 해 보고 싶으면 수락해 줘.

NFKC, 소문자, 영숫자·한글만 남기는 정규화 후에도 응답 중복은 같은 1쌍이며 전체 `answer` JSON이 동일한 경우도 이 1쌍이다. 분할 간 동일 입력·동일 응답·정규화 입력·정규화 응답·동일 입력맥락·동일 그룹 ID는 현재 모든 버전에서 **0쌍**이다. 이 사실은 의미상 유사한 평가 사례까지 독립적이라는 보증이 아니다.

문자열 유사도는 정규화 문자 3-gram TF-IDF cosine, 의미 유사도는 BGE-M3 cosine이다. 각 0.80/0.92를 **검토 후보** 기준으로 사용했다. 이 숫자는 학습된 정답 판정 임계값이 아니다.

| 버전 | 분할 사이 문자 유사 입력 ≥0.80 | 분할 사이 BGE 유사 입력 ≥0.92 | 분할 사이 BGE 유사 응답 ≥0.92 |
|---|---:|---:|---:|
| pilot_v1 | 0 | 0 | 2 |
| pilot_v2 | 0 | 0 | 2 |
| improvement_v1 | 0 | 0 | 1 |
| improvement_v2 | 1 | 2 | 8 |
| improvement_v3 | 0 | 2 | 6 |

모든 버전에서 분할 사이 문자 유사 응답 ≥0.80은 0쌍이다. v3의 주요 의미 근접 사례:

| 경계 | 사례 | BGE cosine | 해석 |
|---|---|---:|---|
| train → test 입력 | `pilot-v1-041` “내 별명도 기억해?” ↔ `f_unrelated` “내 별명 기억하지?” | 0.9802 | 같은 별명 회상 의도. Test에는 무관한 목표를 말한 recent가 있어 전체 입력이 같지는 않음 |
| train → test 입력 | `pilot-v1-010` “공부 시작하게 응원해줘.” ↔ `f_repeat_study` “공부 시작할 용기를 줘.” | 0.9330 | 같은 응원 의도. Test는 최근 반복 답변 회피 조건이 추가됨 |
| train → validation 응답 | `improvement-v1-075` ↔ `expanded-v2-0241`의 걷기·어깨 풀기·아프면 멈추기 | 0.9850 | 상황과 표현이 매우 가까워 일반화 평가를 쉽게 만들 수 있는 후보 |
| train → validation 응답 | `improvement-v1-083`/`expanded-v2-0193` ↔ `improvement-v1-109`의 500걸음 제안 | 각 0.9467 | 동일 Catalog 설명 템플릿 반복 |
| train → validation 응답 | `expanded-v2-0200` ↔ `improvement-v1-108`의 거절한 걷기 재권유 금지 | 0.9230 | 같은 경계 처리 패턴 |

‘확정 leakage 8건’이라고 합산하면 안 된다. 입력만 비슷하고 맥락이 다른 시험도 있고, 하나의 validation 답변과 여러 train 답변이 연결되는 경우도 있다. 원본 split은 그대로 보존했다. 다음 데이터셋에서는 표현이 달라도 같은 사건·정답 논리·대조쌍 가족을 하나의 split에 묶는 검토가 필요하다.

## 응답 다양성과 반복 패턴

| 지표 | Train 216 | Validation 43 |
|---|---:|---:|
| 평균 문장 수 | 1.72 | 1.53 |
| 실제 Qwen 평균 speech 토큰 수 | 17.79 | 16.84 |
| Qwen 토큰 수 중앙값 | 18 | 15 |
| Qwen 토큰 수 최소–최대 | 9–29 | 9–24 |
| Distinct-1 | 0.5444 | 0.7642 |
| Distinct-2 | 0.8800 | 0.9382 |
| `?` 포함 응답 | 8 (3.7%) | 2 (4.7%) |

Distinct는 문장마다 Unicode 단어/어절에 가까운 단위로 분리했다. 형태소 분석 지표나 Qwen subword 다양성과 혼동하면 안 된다. 짧은 응답은 Distinct-2가 높게 나와도 말하기 행동이 반복될 수 있다.

Train의 시작 단어는 `지금` 10회, `흥` 10회, `응` 10회, `지금은` 9회, `알겠어` 7회, `500걸음` 5회다. “그랬구나”는 0회, “괜찮아”는 10/216, “천천히”는 12/216, “잠깐”은 22/216, “확인”은 29/216이다. Validation에서는 각각 “그랬구나” 0회, “괜찮아” 1/43, “천천히” 4/43이다. 특정 상투어가 모두 많다고 가정하지 않고 실제 출현을 셌다.

정규식으로 문장 행동을 분류한 구조 근사치에서는 `진술 → 진술` 50/216, `진술` 36/216, `인정/받아주기 → 진술` 21/216이 많다. 이는 구문 분석이나 사람 평가가 아니라 반복 구조를 찾는 보조 지표다. 질문 예제가 8건뿐이라 curiosity에 따른 질문 빈도 학습을 보장할 근거도 없다.

특정 문구와 기존 축의 연결은 더 강하다. `bluntness ≥70` 13건 중 **10건(76.9%)**이 “흥”을 포함하고 나머지 203건은 0건이다. 이진 phi 상관은 **0.8706**이다. `roughness ≥70` 13건 중 4건이 “젠장”을 포함하고 나머지 203건은 0건(phi **0.5428**)이다. 특정 축을 문장 시작 감탄사로만 표현하는 쉬운 패턴을 모델이 배울 위험이 있다. 상관관계가 모델의 실제 행동에 대한 인과 증거는 아니다.

v3 전체에서의 실제 유사도:

| 대상 | 쌍 수 | 평균 문자열 cosine | 평균 BGE cosine | BGE ≥0.92 |
|---|---:|---:|---:|---:|
| 사용자 입력 317건 | 50,086 | 0.00343 | 0.48877 | 86쌍 |
| 정답 응답 259건 | 33,411 | 0.00462 | 0.48884 | 15쌍 |

| 5 | 24 | 질문/퀘스트 강요 없이 곁에 있기 |
| 6 | 19 | 목표·시간 정정 |
| 7 | 64 | 휴식, 가벼운 움직임, 안심시키기 |

## 성격 대조쌍과 사실 정합성

동일 사용자 입력에 서로 다른 기존 traits가 있는 그룹은 train 5개, validation 2개, test 2개다. 그러나 대부분 traits와 함께 speech_level, profanity 또는 mood도 달라진다.

다른 맥락을 완전히 고정하고 traits만 달라지는 쌍은 train **4쌍**, validation **4쌍**, test **4쌍**이다. Train의 4쌍은 각각 우산·버스·책상 정리·조용히 곁에 있기 상황에서 playfulness/bond/courtesy/bluntness를 동시에 바꾼 예제다. 네 쌍 모두 응답이 다르지만, **개별 축 효과를 분리한 실험은 아니다**. Test에는 참조 응답이 없으므로 답변 차이를 계산할 수 없다.

- 새로운 네 축 각각의 단독 변경 supervised 대조쌍: **모두 0쌍**.
- 새로운 네 축이 응답에 직접 영향을 준다고 데이터에서 확인할 수 있는 레코드: **0건**. 축값 자체가 없다.
- 새 축의 5단계, 상반된 축 조합, mood와 독립된 장기 성격 변화 대조: 확인할 구조화 라벨 없음.
- 레코드에 실제 렌더링된 `system` 문자열은 저장되어 있지 않다. 따라서 “system 문자열만 바뀜”을 그대로 비교할 수 없다. 대신 동일 입력·다른 context·유사 응답을 검사했다. v3에서 문자열 ≥0.80 또는 BGE ≥0.92에 해당하는 쌍은 0이다. 이것이 새 네 축 구별에 성공했다는 뜻은 아니다.

자동 정합성 점검에서 제공되지 않은 memory ID 참조, 후보에 없는 `offer_quest`, non-null `personality_update`, profanity=none에 지정 비속어가 들어간 사례는 **0건**이었다. 완전한 자연어 사실 검증기로 해석하지 않는다.

휴리스틱이 추가로 8건을 검토 후보로 골랐다. 그중 6건은 casual 설정에서도 과제 대행 거절을 존댓말로 하라는 당시 프롬프트 정책에 해당했다. `improvement-v1-089`의 “완료했다고 말할 수는 없어”는 완료 단정이 아니라 부정문이어서 오탐이었다. `expanded-v2-0232`의 “챙겼네”는 현재 사용자 발언을 받아준 것이어서 없는 기억의 발명이 아니었다. **후보 8건을 읽은 범위에서는 확정 정합성 오류 0건**이며, 259건 전체의 의미적 안전성을 사람 검수로 확인했다는 뜻은 아니다.

기존 데이터의 `human_review`/`review.human` 기준 사람 검수 완료 표시는 모든 버전에서 **0건**이다. 새 축이 없으므로 새 축과 말투의 모순을 이 데이터에서 직접 채점할 수도 없다.

## 규칙·프롬프트·추가 학습 문제의 구분

| 문제 | 담당 영역 | 데이터 감사에서 확인한 근거/필요 조치 |
|---|---|---|
| 수치 변화, 중복, cap, streak, 실패 누적, 보상 검증 | 결정론적 규칙 엔진 | 정답 문장을 늘려서 서버 권한을 대신하게 하면 안 됨 |
| 새 네 축과 mood의 의미, style profile, provenance, 선택된 Catalog만 설명 | Prompt/Context | 학습 context는 옛 7축이므로 명시적 새 의미와 제약 전달 필요 |
| 특정 축을 무시하거나 “흥” 같은 단어에만 의존 | 대조 데이터 및 필요 시 LoRA | 직접 4축 supervised 사례 0, 옛 bluntness–흥 상관 0.871 |
| 비슷한 응답 구조, 소수 표현 편중 | 데이터 구성 및 필요 시 LoRA | 1–2문장 구조 편중과 의미 근접 응답 확인 |
| 실제 네 축 반응이 어느 정도 가능한지 | 실제 모델 평가 | 데이터 분석만으로 충분/불충분한 출력 성능을 확정할 수 없음 |

추가 데이터 제작은 필요하다. 재학습은 새로 검수한 데이터와 분리된 평가 세트를 먼저 확보한 다음, 현재 adapter의 반복 A/B 결과와 비교하여 진행해야 한다. 이번 감사에서 재학습의 개선 효과를 실험하거나 보장하지 않았다.

## 제안하는 데이터 구성과 수량

아래는 **후속 수작업 제작·검수 계획**이다. 생성하거나 기존 파일에 넣지 않았다. 첫 목표는 train **600**, validation **120**, test **240**개의 독립적으로 검수된 응답 사례다. 숫자 채우기보다 각 셀의 차이와 사실 정확성을 우선한다.

| 구성 | Train | Validation | Test |
|---|---:|---:|---:|
| 각 축 단독 대조: 20↔80, 다른 상태·입력·memory 고정 | 축당 50쌍 = 400응답 | 축당 10쌍 = 80응답 | 축당 20쌍 = 160응답 |
| 축 조합·5단계·mood 분리·장기 변화 상황 | 80응답 | 20응답 | 40응답 |
| 기록 근거·거절·정정·Catalog·실패/휴식 설명 | 120응답 | 20응답 | 40응답 |
| 합계 | 600 | 120 | 240 |

단독 대조쌍은 curiosity/affection/activity/confidence 각각 총 80쌍, 합계 320쌍이다. 축별 같은 사건과 문장 변형은 반드시 같은 split에 둔다. 각 split의 축별 50/10/20개 상황 가족을 독립적으로 확보하고, 운동·식생활·일상·퀘스트·기억·거절의 6영역을 모두 포함한다. 최소 train 60개/validation 12개/test 24개의 서로 다른 **기본 상황 가족**을 준비하고, 축마다 독립적인 선택·질문·표현 결정을 요구하도록 배정한다. 같은 원문을 이름·숫자만 바꿔 가족 수를 늘리지 않는다. 대조쌍의 두 답변은 어미 하나가 아니라 질문 여부, 제안의 순서, 정서 표현, 반응 길이 중 두 가지 이상이 구분되어야 한다.

필수 내용은 다음과 같다.

1. **curiosity:** 새 운동/새 음식/새 주제에서 질문하기와 바로 받아주기의 차이, 이미 설명한 사실을 반복 질문하지 않기, “질문하지 마” 요청이 호기심보다 우선하기.
2. **affection:** 친근한 공동 경험 표현과 정중한 거리 유지. 낮아도 무례하지 않고, 높아도 없는 공유 기억을 만들지 않기.
3. **activity:** 짧은 선택지 제안과 적극적 실행 제안의 차이. 높은 상태에서도 피로·통증·거절을 우선하기.
4. **confidence:** 명확하게 선택을 설명하되 사실의 확실성은 provenance로 유지하기. 낮은 상태에서도 모든 문장을 모호하게 만들지 않기.
5. **조합과 상태:** activity 80/confidence 20, affection 80/mood low, 높은 curiosity/energy 20, 다섯 단계 경계 인근, Day 0/Day 14/Day 30의 실제 엔진 결과를 사용한 상황.
6. **근거와 퀘스트:** 사용자 자기보고/검증된 기록/미검증 사진/unknown 영양소, 기록 정정·삭제, 최근 실패, 거절 활동, 반복 제한, 동일 Catalog 사실을 유지하며 설명 방식만 바꾸기.

유지할 후보는 JSON 계약, 사진≠섭취, 기억 없음/정정/삭제, 확인된 활동 합계, 서버 후보만 제안, 휴식·거절 존중이다. 원본은 그대로 두고 후속 버전에서 source ID와 이유를 기록해 재사용 여부를 결정한다.

수정·제외 검토 후보는 동일 500걸음 답변 1쌍, 의미상 거의 같은 스트레칭/거절 템플릿, “흥”에 의존하는 말투, traits와 mood/speech_level이 동시에 변하는 대조, 네 축 의미가 없는 스타일 예제다. 전부 자동 삭제하면 경계 규칙 coverage도 잃으므로 중복률만 보고 제거하지 않는다. legacy 예제를 새 축으로 환산할 때는 명시적인 재작성·검수가 필요하며 기계적 필드명 변경은 하지 않는다.

예상 효과는 새 축을 독립적인 말하기 행동과 연결하고 mood를 장기 성격으로 오인하는 일을 줄이는 것이다. 실제 효과는 보장하지 않는다. 과적합을 줄이려면 사건 가족·대조쌍·가까운 템플릿을 한 split에 묶고, 모든 5단계를 골고루 검수하고, 상투어–축 연관을 다시 측정하고, 미리 동결한 새 test를 모델 선택에 사용하지 않아야 한다. Test 일부는 제작자와 다른 검수자가 사실 보존·자연스러움·축 구분을 함께 판정해야 한다.

## 이번 감사의 판정 범위

- **A. 성격 변화 시스템을 게임 규칙으로 사용할 수 있는가?** 이 문서는 데이터 감사이므로 엔진의 실행 테스트·30일 시뮬레이션 결과에서 판단한다. 기존 학습 데이터가 수치 규칙의 정답 또는 근거가 되어서는 안 된다.
- **B. 현재 LoRA가 성격별 말투를 충분히 구분하는가?** 기존 데이터만으로 새 네 축의 충분한 구별을 입증할 수 없다. 옛 스타일을 일부 구분하도록 만든 데이터는 있으나 단일 축 대조와 폭넓은 상태 조합이 없다. 최종 판정은 실제 Qwen 반복 A/B 평가와 합쳐야 한다.
- **C. 추가 데이터와 LoRA 재학습이 필요한가?** 네 축을 안정적으로 학습·평가하려면 추가 데이터 제작이 필요하다. 기존 데이터 그대로의 재학습은 네 축 라벨 부재를 해결하지 않는다. 검수된 새 대조 데이터 확보 후, 실제 평가에서 지속되는 스타일 실패를 대상으로 재학습을 검토한다.
