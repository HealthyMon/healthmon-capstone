# 상태·기억·Agent 계약 v1

기본 이름은 몽글이, 종족은 펭귄이다. `config/rules.json`과 `src/contracts.py`가 실행 규칙과 응답 계약의 기준이다. Unity 구현 코드가 인접 저장소에 없어 `healthmon.v1`은 임시 연동 계약이다.

| 입력 | 변경 가능 축 | 최소 근거 | 변화 | 제한 |
|---|---|---|---|---|
| 장난 대화 | playfulness | 새 발화 5개 시점, 서로 다른 근거 3개·서버 세션 2개 | +1 | 축별 1회 2, 현지 날짜 절댓값 합 5 |
| 감사·격려 대화 | bond | 위와 동일 | +1 | 0~100, 같은 속도 제한 |
| 공손한 교감, 새침한 말투를 즐기는 교감, 상황을 향한 가벼운 비속어 | courtesy, bluntness, roughness | 축별 서로 다른 근거 3개·서버 세션 2개, 새 발화 5개 시점 | +1 | 사용자 비속어 상한은 변경하지 않음 |
| 확인된 걷기 | initiative | 서로 다른 이벤트 3개·날짜 2개 | +1 | 위와 동일 |
| 확인된 음식 경험 | sociability | 서로 다른 이벤트 3개·날짜 2개 | +1 | 음식 종류로 도덕성 평가하지 않음 |
| 피곤함 표현 | 기분 valence/energy | 현재 사용자 발화 | -10/-8 | 장기 성격 변화 없음 |
| 장난·감사, 확인된 걷기 | 기분 valence | 현재 근거 | +8 또는 +10 | -100~100 |

기분은 원본 시각에서 valence 30분, energy 60분 반감기로 기본 0/50에 접근한다. 요청 횟수로 감쇠하지 않는다. 장기 성격에 중립 복귀는 없다. 말투 축은 명시한 대화 패턴이 누적될 때만 서서히 올라간다. 같은 질문의 강제 상태 비교는 자연 성장 검증과 구분한다. LLM personality_update는 v1에서 항상 null이며 서버 규칙만 상태를 변경한다.

복사 및 유사 표현을 문자 정규화·유사도 기준으로 제거한다. 의미가 같은 모든 의역을 완벽히 판별하는 것은 아니므로 의미 중복 검수는 별도 필요하다. 세션은 마지막 유효 발화로부터 30분 간격으로 서버가 발급한다.

최근 6교환과 BGE-M3 dense 1024차원 검색 상위 3건을 사용한다. 임시 임계값 0.5는 작은 파일럿용이며 아직 검색 품질 목표를 달성한 값으로 간주하지 않는다. 원본 사용자 발언만 기억으로 승격하고, 명시적 선호·목표는 자동 보존한다. 경험은 인증된 API로 원본을 지정한다. 같은 slot의 새 선호/목표는 기존 활성 기억을 대체한다. 여러 세부 취향의 병행 슬롯은 확장 필요하다. 선택적 시각 필터와 실제 활동 기간 합계를 제공한다.

원본 수정·삭제 시 파생 벡터·내용, 응답 캐시·최근 답변을 무효화한다. 수정 전 원본 내용은 DB에 남기지 않는다. 상태 이력도 유효한 원본으로 재계산한다. 안전한 단순화를 위해 같은 펫의 파생 답변 전체를 무효화하므로 무관한 최근 답변도 사라질 수 있다. PostgreSQL 백업/WAL의 물리적 삭제까지 보장하는 정책은 별도 운영 범위다. ‘방금 말한 걷기 취향은 기억하지 마’처럼 명시한 슬롯과 유일한 활성 원본이 일치하는 삭제는 인증된 서버 규칙으로 처리한다. ‘그거 기억하지 마’처럼 모호한 대상은 확인 질문을 한다. 나머지 정정/삭제는 관리 API에서 명시한 ID를 사용한다.

과제 완성본 대행은 제품 역할 밖이다. 과제 스트레스, 응원, 일반 운동 루틴은 허용한다. 기억과 사용자 발화의 지시는 시스템 권한을 바꾸지 못한다. JSON/schema, 후보와 기억 ID, 권한을 검사하고 보정과 반복 회피를 합쳐 추가 생성은 1회다. 형식 검사로 자연어 주장 전체의 사실성을 입증할 수 없으며 실제 응답 의미 검토는 별도 보고한다.

퀘스트는 로컬 게임 검증용 500/1000걸음 템플릿이다. 현재 추천은 500걸음만 활성화했다. 1000걸음으로의 자동 난도 증가는 미활성이다. 제안 간격 30분, 명시 요청은 간격 예외, 거절 후보는 현지 당일 재제안하지 않는다. 목표 완료 당일 추가 제안은 막는다. 제안은 시작이 아니며 수락 API와 상태 버전 검사가 필요하다. 확인된 backend/sensor 활동만 진행/보상에 반영한다. 원본 수정으로 완료가 취소되면 보상 원장에 상쇄 항목을 기록한다. 확인된 활동의 제안 대기 작업은 영속 저장하며, 활동 제안 API를 호출하면 로컬 Qwen이 판단해 제안을 저장한다. 팀 실제 성장·보상 규칙은 아직 확보되지 않았다.

인증은 로컬 개발 토큰 2개와 별도 producer 토큰이다. 팀 서버 인증으로 교체해야 한다. DB/HTTP는 127.0.0.1에만 바인딩한다. `user_id`를 요청 본문에서 받지 않으며 모든 조회는 인증 사용자와 pet_id 소유권을 확인한다.
